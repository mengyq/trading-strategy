# A股多因子量化交易策略

## 概述
基于MA多周期多头排列 + MACD金叉 + RSI + 成交量确认的趋势跟踪策略。

## 核心参数（p2_sl7_tr10）
- 持仓: 2只股票, 各50%
- 止损: 7% (严格止损)
- 移动止盈: 从最高点回落10%
- 买入: MA5>MA10>MA20>MA60>MA200 + MACD金叉 + RSI 40-65 + 放量>1.2倍
- 卖出: 止损7% / 移动止盈10% / 时间止损30天 / 止盈30%

## 5年回测结果 (2021-2026)
- 总收益: +133.32%
- 年化: 18.22%
- 盈亏比: 3.14
- 胜率: 67%
- 最大回撤: -18.49%
- 交易次数: 24笔

## 使用方法
1. 安装依赖: pip install pandas numpy matplotlib akshare
2. 运行回测: python outputs/bt_v7_6.py
3. 查看每日信号: python work/live_signal.py
